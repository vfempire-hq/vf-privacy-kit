# vf-privacy-kit — API reference

Same API across Rust / TypeScript / Swift / Kotlin. Documented here in Rust prose; each language target maps the types straightforwardly.

## `identity`

### `IdentityPublic`

Public half of an identity. Safe to share, log, or store in a directory-of-users.

```rust
pub struct IdentityPublic {
    pub enc_pk:  [u8; 32],   // X25519 public key (age-compatible)
    pub sign_pk: [u8; 32],   // Ed25519 public key
    pub id_hash: [u8; 32],   // BLAKE3(enc_pk || sign_pk)
}
```

### `Identity::from_seed(seed: &[u8; 32]) -> (IdentityPublic, IdentitySecret)`

Deterministically derives an identity from a 32-byte seed. The seed is the ONLY thing the user needs to back up; everything else regenerates from it.

Errors: `Error::Input` if seed is not exactly 32 bytes.

### `IdentityPublic::to_display() -> String`

Encodes as `vfid_<base32-crockford>` for human verification. Exactly 40 chars.

## `channel`

### `Envelope`

Wire format for a sealed message.

```rust
pub struct Envelope {
    pub routing_hash: [u8; 32],  // BLAKE3(recipient.id_hash || salt)
    pub salt:         [u8; 16],
    pub sealed_body:  Vec<u8>,   // age-encrypted to recipient.enc_pk
    pub signature:    [u8; 64],  // Ed25519(sealed_body || salt) by sender.sign_sk
}
```

### `Channel::seal(recipient: &IdentityPublic, sender_secret: &IdentitySecret, plaintext: &[u8]) -> Envelope`

Produces a wire envelope. Salt is fresh-random per call.

### `Channel::open(envelope: &Envelope, sender: &IdentityPublic, recipient_secret: &IdentitySecret) -> Result<Vec<u8>>`

Verifies the sender's signature, decrypts the sealed body. Returns `Error::Verification` if the signature is bad or the recipient's key doesn't match.

### `Channel::route_hash(recipient: &IdentityPublic, salt: &[u8; 16]) -> [u8; 32]`

The routing hash a server can index on. Same-recipient envelopes yield different hashes because of the salt.

## `pack`

### `PackManifest`

Header of a sealed offline pack.

```rust
pub struct PackManifest {
    pub product:                 String,   // e.g. "nav-it"
    pub region:                  String,   // e.g. "DE"
    pub version:                 String,   // monotonic
    pub body_size:               u64,
    pub body_hash:               [u8; 32], // BLAKE3 of body
    pub built_at:                String,   // RFC 3339
    pub signing_key_fingerprint: String,
}
```

### `Pack::seal(manifest: &PackManifest, body: &[u8], signing_key: &Ed25519Signer) -> Vec<u8>`

Produces a pack file. Format:

```
magic:           "VFPK"
version:         u32 le
manifest_length: u32 le
manifest:        canonical-JSON bytes
signature:       Ed25519(manifest || body_hash)
body:            content bytes
```

### `Pack::open(bytes: &[u8], expected_signer_pubkey: &[u8; 32]) -> Result<(PackManifest, &[u8])>`

Verifies signature + body-hash. Returns the manifest + a slice into the body. `Error::Verification` on signature mismatch, `Error::Format` on malformed bytes.

## `token`

### `Token::derive(minute: u64, key: &[u8]) -> [u8; 32]`

Compute the token for a given (minute, key). Uses `HMAC-BLAKE3`.

### `Token::verify(candidate: &[u8; 32], now_minute: u64, current_key: &[u8], previous_key: Option<&[u8]>) -> bool`

Constant-time check across the ±2-minute rolling window using either the current or previous key. Returns `true` on any match.

---

## `wipe`

### `Wipe::register_wipe_target(scheme: &str, handle: &str)`

Register a persistent store (file path, keychain entry, IndexedDB name) that a panic-wipe should include. Call during app boot for every store holding key material.

### `Wipe::panic_wipe() -> usize`

Execute the wipe. Zeroizes every registered target + the in-memory key cache. Returns the number of targets that were successfully zeroized. Best-effort: partial wipe is better than none.

## Cross-language mapping

The same conceptual types map to each language's idioms:

| Rust             | TypeScript                | Swift            | Kotlin            |
|------------------|---------------------------|------------------|-------------------|
| `[u8; 32]`       | `Uint8Array` (length 32)  | `Data`           | `ByteArray`       |
| `Vec<u8>`        | `Uint8Array`              | `Data`           | `ByteArray`       |
| `String`         | `string`                  | `String`         | `String`          |
| `Result<T, E>`   | throws / Promise<T>       | `throws` / `Result` | `Result<T>`   |
| `Option<T>`      | `T \| null`               | `T?`             | `T?`              |
| `struct`         | `interface`               | `struct`         | `data class`      |

The Rust API is canonical; the other three are generated by `uniffi-rs` (Swift + Kotlin) or hand-written to match (TypeScript via WASM).
